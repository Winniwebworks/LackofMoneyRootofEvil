# Lack of Money is the Root of All Evil

Static demo website (HTML + CSS, no build step). Open `index.html` in a browser or serve the folder with any static host (for example, GitHub Pages).

## Pages
- `index.html` – Home: Mark Twain portrait and quote
- `photos.html` – Photos (placeholder, images to be added later)
- `donate.html` – Donate: PayPal button and "Would you like a world where" content
- `about.html` – About: book introduction and FREE PDF download link
- `404.html` – Not-found page (not in the nav)
